# WCC — Веб-контакт-центр

Интерфейс оператора контакт-центра: топбар, боковое меню, рабочая область, панель заказа и карточка клиента.

## Стек

- **React 19** + **TypeScript**
- **Vite 7**
- Vanilla CSS (дизайн-токены в `src/styles/tokens.css`)

## Скрипты

| Команда     | Описание                    |
|------------|-----------------------------|
| `npm run dev`    | Запуск dev-сервера          |
| `npm run build`  | Сборка для продакшена       |
| `npm run preview`| Просмотр собранного билда   |
| `npm run lint`   | ESLint                      |
| `npm run test`   | Vitest                      |
| `npm run shot`   | Playwright: скриншоты UI    |

## Запуск

```bash
npm install
npm run dev
```

Приложение доступно на **http://localhost:55173** (или `http://wcc.local:55173` при настроенном хосте).

Порт задаётся в `vite.config.ts`; для скрипта скриншотов можно передать `PORT=55173 npm run shot`.

## Особенности

- Состояние меню из URL: `?menu=open` — меню открыто при загрузке.
- Адаптив: 1200px (правая колонка вниз), 900px (одна колонка, горизонтальное меню).
- Доступность: ARIA, `:focus-visible`, `prefers-reduced-motion`.
- **Agentation** — аннотации по UI для AI-агентов (только в `npm run dev`).

## Agentation: как пользоваться

[Agentation](https://agentation.dev) — dev-тулза для аннотирования элементов на странице. Она помогает давать AI-агентам (Cursor, Claude Code и т.п.) точные селекторы и контекст вместо расплывчатых описаний.

**Включение:** панель появляется **только в dev** (`npm run dev`). В прод-сборке Agentation не подключается.

### Шаги

1. Запусти `npm run dev` и открой приложение в браузере.
2. В правом нижнем углу появится **иконка Agentation** — нажми её, чтобы включить режим аннотаций.
3. **Наводи курсор** на элементы — подсвечиваются имена/классы (например, `.wcc-side__burger`, `.wcc-shiftToggle`).
4. **Кликни** по элементу — откроется форма. Напиши, что не так или что изменить, и нажми **Add**.
5. Можно **выделить текст** на странице и добавить аннотацию (удобно для опечаток и правок контента).
6. Кнопка **копирования** в тулбаре — скопирует markdown с селекторами, путями и твоими заметками.
7. **Вставь** этот текст в чат с Cursor (или другим агентом). Агент сможет искать по `.wcc-topbar__group--shift` и т.д. и быстрее найти нужный код.

### Советы

- **Одна проблема — одна аннотация.** Так агенту проще править по шагам.
- **Будь конкретен:** «Кнопка „Смена“ должна быть выше» лучше, чем «здесь что-то не так».
- **Укажи контекст:** что ожидаешь vs что видишь.
- **Пауза анимаций** — в тулбаре есть кнопка заморозить анимации, чтобы зафиксировать нужный кадр.
